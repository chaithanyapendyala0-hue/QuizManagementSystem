Quiz Management System

Project Overview

The Quiz Management System is a console-based Java application that allows users to participate in a quiz, answer multiple-choice questions, and view their scores.

Technologies Used

- Java
- Eclipse IDE
- Java Scanner Class

Features

- Start a quiz with 10 multiple-choice questions.
- Display correct and wrong answer messages.
- Show the correct answer when a response is incorrect.
- Calculate the total score out of 10.
- View the latest quiz result.
- Validate user input.
- Exit the application.

Project Structure

QuizManagementSystem/
└── src/
    └── quiz/
        └── QuizApp.java

How to Run

1. Open Eclipse IDE.
2. Import or create the Java project.
3. Open "QuizApp.java".
4. Run the program as a Java Application.
5. Select an option from the menu.
6. Start the quiz and answer the questions.
7. View your result after completing the quiz.
